# Statistics Projects

This section demonstrates applied statistics skills used in day-to-day data analysis work.

## Objective

Show the ability to use statistical concepts to describe data, test hypotheses, and support data-driven decisions.

## Suggested Project: A/B Test & Descriptive Statistics Analysis

- Compute descriptive statistics (mean, median, mode, variance, standard deviation) on a sample dataset.
- Explore probability distributions and visualize them (normal, binomial).
- Run a hypothesis test (e.g. two-sample t-test) comparing two groups, such as an A/B test on conversion rates.
- Calculate and interpret p-values, confidence intervals, and effect size.
- Explore correlation and simple linear regression between two variables.

## Skills Demonstrated

- Descriptive statistics and data summarization
- Probability distributions
- Hypothesis testing (t-tests, chi-square tests)
- Confidence intervals and p-value interpretation
- Correlation and regression analysis
