# Excel Projects

This section demonstrates spreadsheet analysis and reporting skills using Microsoft Excel.

## Objective

Show the ability to clean, model, and summarize data in Excel to produce business-ready reports and dashboards.

## Suggested Project: Sales Performance Dashboard

- Import a raw sales dataset (CSV) and clean it (remove duplicates, fix formatting, handle blanks).
- Build PivotTables to summarize revenue by region, product, and month.
- Use formulas such as VLOOKUP/XLOOKUP, INDEX-MATCH, SUMIFS, and COUNTIFS to combine and analyze data.
- Create charts (bar, line, pie) and a one-page interactive dashboard with slicers.
- Highlight key KPIs: total revenue, growth rate, top products, and top regions.

## Skills Demonstrated

- Data cleaning and formatting
- PivotTables and PivotCharts
- Lookup formulas (VLOOKUP, XLOOKUP, INDEX-MATCH)
- Conditional formulas (SUMIFS, COUNTIFS, IFERROR)
- Dashboard design with slicers and conditional formatting
