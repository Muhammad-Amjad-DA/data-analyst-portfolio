# SQL Projects

This section demonstrates data querying and database skills using SQL.

## Objective

Show the ability to extract, join, aggregate, and analyze relational data to answer real business questions.

## Suggested Project: Sales & Customer Analysis

- Load a public dataset (e.g. a sample e-commerce or sales database) into PostgreSQL/MySQL.
- Write queries to find top customers, monthly revenue trends, and product performance.
- Use joins across orders, customers, and products tables.
- Use window functions (RANK, ROW_NUMBER, LAG/LEAD) to find running totals and month-over-month growth.
- Use CTEs to break complex logic into readable steps.

## Skills Demonstrated

- SELECT, WHERE, GROUP BY, HAVING
- INNER/LEFT/RIGHT JOIN
- Subqueries and CTEs
- Window functions
- Aggregate functions (SUM, COUNT, AVG)
- Query performance basics (indexes, EXPLAIN)
